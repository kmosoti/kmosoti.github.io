# Interactive Resume Phase 1

This branch contains the first phase of a new interactive resume concept for the GitHub Pages site.

## Scope

Phase 1 includes:
- Hero and positioning section
- Capability map grouped by engineering domain
- Public-safe case study summaries
- Demo lab placeholder
- Link section tying the resume back to GitHub and LinkedIn

## Intent

This version is meant to establish a stronger public narrative around:
- automation
- observability
- infrastructure
- AI-assisted engineering

It does not yet replace the current site. It lives in its own folder so it can be reviewed independently.

- `app.js`
