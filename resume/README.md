# Developer Mono Resume

This directory keeps the resume in a simple source-first format.

## Files
- `resume.json` is the canonical content source.
- `index.html` is a lightweight render inspired by JSON Resume's Developer Mono direction.

## Intent
The structure is meant to be easy to iterate on later if you want to:
- switch to a stricter JSON Resume CLI flow
- add generated PDF export
- turn this into a more agentic portfolio workflow where resume content, portfolio highlights, and project summaries are driven from a single source
