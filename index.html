Kennedy Mosoti

Observability platform engineer in Dallas–Fort Worth, Texas.

My passion is designing robust systems — separating each major component so that each aspect can be optimized to fit its use case. This is where observability and platform work come in.

I enjoy designing observability platforms and standardized telemetry that give insight into the health of any system. That data and insight can then be leveraged to tweak a system so it runs smoother.

I find the same data usually informs the feature work, too.

Work

I'm an observability engineer at Netbuilder, on the log platform at JPMorgan Chase in Plano, Texas. It's a Splunk platform big enough that most things have to be automated, and automating them is most of what I do.

  • Access — search-filter updates across about 3,000 Splunk roles, done in Python instead of by hand.
  • Rollout — Salt-driven automation across 100+ search heads, so a platform-wide change is one job rather than a hundred.
  • Ingestion — Kafka into Logstash into Splunk: stale-topic cleanup, and Logstash consumers when they stop keeping up.
  • Recovery — I wrote up the disaster-recovery readiness gaps around the cluster manager and the deployer, and did the root cause and remediation on farm breaks, including a 40-host reboot.

Outside work I build small tools — inspection utilities, and boundaries that keep coding agents inside what they were handed. This site's build system is one of them: every change goes through automated checks before anyone judges how it looks.
